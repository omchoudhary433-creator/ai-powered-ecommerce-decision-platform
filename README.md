# AI-Powered Intelligent E-Commerce Decision Platform

## Project Overview
The AI-Powered Intelligent E-Commerce Decision Platform is a Python-based analytics dashboard designed to help e-commerce businesses understand sales performance, customer behaviour, product popularity, and inventory status through interactive visualizations and data-driven insights.

## Key Features
- **Executive Dashboard:** Overview of business performance and monthly sales trends.
- **Customer Intelligence:** RFM-based customer analysis, customer segmentation, and customer cluster information.
- **Product Recommendations:** Identifies popular products using historical sales data.
- **Sales Forecasting:** Displays historical monthly revenue and forecast values generated by the analysis notebook.
- **Inventory Management:** Add, view, and delete inventory records using SQLite.
- **Sentiment Analysis:** Text sentiment analysis using VADER.

## Technology Stack
- Python
- Pandas
- Streamlit
- SQLite
- Jupyter Notebook
- Matplotlib / Streamlit charts
- VADER Sentiment Analysis
- CSV-based data processing

## Installation and Execution

1. Install Python 3.
2. Open Command Prompt in the project directory.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Start the dashboard:

   `streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Data and Analysis
The project uses transaction-level e-commerce data to prepare customer-level RFM metrics, customer segments, product sales summaries, monthly revenue summaries, and forecast output. The Streamlit dashboard reads the generated CSV outputs from the `outputs` directory.

## Limitations
- Product popularity analysis is not a personalized recommendation engine.
- Forecast quality depends on the forecasting method used in the notebook.
- Sentiment results depend on the capabilities of the VADER lexicon.
- Output CSV files must be generated before the corresponding dashboard sections can display their analysis.

## Expected Outcome
A working interactive dashboard that presents e-commerce sales, customer, product, inventory, and sentiment information to support business analysis and decision-making.
